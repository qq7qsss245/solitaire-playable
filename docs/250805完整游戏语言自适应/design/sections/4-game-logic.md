# 5. 游戏逻辑

### 自适应语言模板以及卡牌叠放逻辑可参考 “Solitaire_自研十字_自适应多语言Rick_Farren_250410” （附在文件夹参考中）


## 5.1 核心玩法
- 当前配置：
  * 卡牌总数：52
  * 卡牌花色：4
  * 倒计时时间：采用正计时
  * 结束条件：成功将所有卡牌按花色从小到大顺序排列至卡槽  or  无操作时间达到30s
  * 叠放逻辑：在卡牌卡槽区域，卡牌按照由小到大顺序摆放，且卡槽只能摆放其对应花色的卡牌
            在卡牌翻牌区域，卡牌按照又大到小方式排列，且只能异色相叠，当翻牌区域有空位时，只能放置K

- 交互反馈：
  * 正确点击：当点击为明牌时，卡牌自动移动至对应位置
            当点击为牌堆时，翻开第一张卡牌
  * 错误点击：不做任何反馈

## 5.2 引导系统
- 初始引导：
  * 显示位置：任意可移动的卡牌
  * 动画：手指图标循环缩放
  * 触发条件：游戏开始时

- 游戏中引导：
  * 显示位置：1.任意可移动的卡牌  2.当无卡牌可移动时，则显示于牌堆区域
  * 动画：手指循环缩放，范围为80-120%
  * 触发条件：5秒无操作
  * 消失条件：任意点击

## 5.3 计分系统
- 显示方式：计分板
- 更新逻辑：
  1. 正确点击卡牌
  2. 卡牌移动至对应区域
  3. 若正确点击的卡牌下仍有余牌则自动翻开此牌
  4. 指示器更新为正确状态

## 5.4 计步系统
- 显示方式：计步器
- 更新逻辑：
  1. 正确点击卡牌 或 点击牌堆区域进行翻牌
  2. 指示器更新为正确状态

## 5.5 自动完成条件
- 当游戏区域的所有卡牌均呈翻开状态时，弹出autocomplete按钮
- 使用淡入的效果 完全出现后按钮呈跳动动画，单次动画时间500毫秒，循环播放
- 同步出现引导手指

## 5.6 跳转系统
- 游戏胜利跳转：
  * 完成整局游戏后在end界面任意点击均跳转
  * 完成整局游戏后在end界面5s内无操作自动跳转
- 交互按钮跳转：
  * 自开屏起，任意时间点点击交互按钮即跳转
- 无操作跳转：
  * 自开屏起启动30s倒计时，30s内无操作自动跳转，每次点击后重置

## 5.7 自适应布局系统
- 监听事件：window.resize
- 处理逻辑：
  1. 检测屏幕方向
  2. 更新游戏场景尺寸
  3. 重新计算所有UI元素位置
  4. 重新计算差异点位置和大小

## 5.8 性能考虑
- 当前资源尺寸：未优化
- 动画实现：使用Phaser.Tweens
- 事件系统：使用自定义EventBus
- 内存管理：
  * 正确销毁临时对象（如动画特效）
  * 适当缓存频繁使用的对象
