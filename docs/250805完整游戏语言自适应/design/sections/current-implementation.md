# 1. 项目概述
当前项目是一个基于Phaser 3 + TypeScript开发的找不同游戏。玩家需要在将所有纸牌从小到大按照花色排列摆放至对应花色的卡槽中。

# 2. 技术架构
- 游戏引擎：Phaser 3
- 开发语言：TypeScript
- 构建工具：Vite
- 项目结构：
  ```
  src/
  ├── game/
  │   ├── scenes/         # 游戏场景
  │   ├── components/     # 游戏组件
  │   └── EventBus.ts     # 事件系统
  ├── assets/            # 资源文件
  └── config/           # 配置文件

# 5. 游戏逻辑

## 5.1 核心玩法
- 当前配置：
  * 卡牌总数：52
  * 卡牌花色：4
  * 倒计时时间：采用正计时
  * 结束条件：成功将所有卡牌按花色从小到大顺序排列至卡槽  or  无操作时间达到30s
  * 叠放逻辑：在卡牌卡槽区域，卡牌按照由小到大顺序摆放，且卡槽只能摆放其对应花色的卡牌
            在卡牌翻牌区域，卡牌按照又大到小方式排列，且只能异色相叠，当翻牌区域有空位时，只能放置K

- 交互反馈：
  * 正确点击：当点击为明牌时，卡牌自动移动至对应位置
            当点击为牌堆时，翻开第一张卡牌
  * 错误点击：不做任何反馈

## 5.2 引导系统
- 初始引导：
  * 显示位置：任意可移动的卡牌
  * 动画：手指图标循环缩放
  * 触发条件：游戏开始时

- 游戏中引导：
  * 显示位置：1.任意可移动的卡牌  2.当无卡牌可移动时，则显示于牌堆区域
  * 动画：手指循环缩放，范围为80-120%
  * 触发条件：5秒无操作
  * 消失条件：任意点击

## 5.3 计分系统
- 显示方式：计分板
- 更新逻辑：
  1. 正确点击卡牌
  2. 卡牌移动至对应区域
  3. 若正确点击的卡牌下仍有余牌则自动翻开此牌
  4. 指示器更新为正确状态

## 5.4 计步系统
- 显示方式：计步器
- 更新逻辑：
  1. 正确点击卡牌 或 点击牌堆区域进行翻牌
  2. 指示器更新为正确状态

## 5.5 自动完成条件
- 当游戏区域的所有卡牌均呈翻开状态时，弹出autocomplete按钮
- 使用淡入的效果 完全出现后按钮呈跳动动画，单次动画时间500毫秒，循环播放
- 同步出现引导手指

## 5.6 跳转系统
- 游戏胜利跳转：
  * 完成整局游戏后在end界面任意点击均跳转
  * 完成整局游戏后在end界面5s内无操作自动跳转
- 交互按钮跳转：
  * 自开屏起，任意时间点点击交互按钮即跳转
- 无操作跳转：
  * 自开屏起启动30s倒计时，30s内无操作自动跳转，每次点击后重置

## 5.7 自适应布局系统
- 监听事件：window.resize
- 处理逻辑：
  1. 检测屏幕方向
  2. 更新游戏场景尺寸
  3. 重新计算所有UI元素位置
  4. 重新计算差异点位置和大小

## 5.8 性能考虑
- 当前资源尺寸：未优化
- 动画实现：使用Phaser.Tweens
- 事件系统：使用自定义EventBus
- 内存管理：
  * 正确销毁临时对象（如动画特效）
  * 适当缓存频繁使用的对象



# 7. 详细实现规范

## 7.1 动画系统参数

1. 入场动画
- 透明度：从完全透明渐变到完全不透明
- 持续时间：0.7秒
- 缓动效果：带有弹性的缓出效果
- 牌堆与卡槽：入场即显示
- 卡牌入场：翻牌区域共七列牌，从左到右依次为第一列至第七列，入场后卡牌从牌堆区域依次飞入翻牌区，首列摆放一张卡牌...第七列摆放七张卡牌，每列最上方的牌明牌显示，其余牌均为背面
- 序列延迟：
  * 计分板区域：立即显示
  * 下载按钮：立即显示，显示后呈缩放效果

2. 正确点击或拖动特效
- 翻卡区卡牌正确点击：
  * 卡牌平移至其可摆放的位置
  * 卡牌原所处列的下一张卡牌翻开
  * 卡牌平移动画持续100毫秒
  * 翻卡动画持续100毫秒
  * 卡牌入槽时卡槽周围出现花色闪光，持续时间500毫秒

- 牌堆区卡牌正确点击：
  * 若正确点击待翻开的牌堆，则翻开一张卡牌至牌堆左侧
  * 若正确点击牌堆区已翻开的卡牌，则卡牌平移至其可摆放的位置
  * 动画持续100毫秒

- 计分板更新：
  * 计分板中数字随正确点击更新，字体样式大小不变
  * 翻开卡牌不加分，从翻卡区将卡牌正确移动至游戏区+5，将卡牌归入卡槽+10
  * 使用带有弹性的缓出效果

3. 错误点击动画
- 卡牌左右平移：
  * 平移范围：-10px到10px（相对于原始位置）
  * 单次平移用时100毫秒
  * 连续移动2次
  * 动画结束后回到原始位置

4. 引导手指动画
- 手指图标移动：
  * 缩放范围80-110%
  * 无限循环播放
- 显示和消失：
  * 渐变显示
  * 任意点点击后即刻消失
- autocomplete引导
  * 缩放范围80-110%
  * 手指缩放为80%时，autocomplete按钮开始播放动画，类似引导手指按下按钮效果

5. autocomplete动画
- 玩家点击按钮后，剩余所有未归入卡槽的牌按照按照花色以及从小到大的顺序依此从所在位置平移对应卡槽，过程中卡牌无需旋转
- 单张卡牌动画持续300毫秒以内

6. 胜利动画
- 所有卡牌归入卡槽后，随机从卡槽中飞出围成圆环
- 卡牌中心指向：
  * 竖版圆心：x = 540 , y = 1080
  * 横版圆心：x = 645 , y = 540
- 圆圈显示牌数量：26（即每两张牌入同一个位置，形成遮挡关系），首张牌进入后开始顺时针旋转
- 圆圈转一圈所需时间：5s
- 第一张进入圆圈牌位置-中心点：
  * 竖版：x = 870 , y = 1280
  * 横版：x = 970 , y = 740

## 7.2 事件系统

游戏中的核心事件包括：

1. 卡牌点击事件
- 触发条件：玩家点击到可移动或可翻开的卡牌
- 传递信息：
  * 卡牌原始位置信息
  * 卡牌移动后的位置信息
- 处理流程：
  * 更新游戏分数
  * 播放正确点击动画
  * 播放卡牌翻动音效
  * 更新计步板/计分板显示
  * 检查是否达到结束条件

2. 点击失误事件
- 触发条件：玩家点击到不可移动的卡牌 或 其他非游戏区域
- 点击到不可移动的卡牌处理流程：
  * 播放错误点击动画
  * 播放错误音效
- 点击到非游戏区域处理流程：
  * 不做任何反馈


3. 游戏结束事件
- 触发条件：完成整局游戏  or  无操作时间达到30s
- 处理流程：
  * 停止所有游戏操作
  * 显示结算画面
  * 显示胜利界面 or 自动跳转


## 7.3 状态管理

1. 游戏状态说明：

- 游戏开始标志
  * 用途：控制游戏是否已经开始
  * 影响：引导显示和计时启动
  * 变更时机：玩家首次点击

- 当前得分
  * 用途：显示已正确点击的分数
  * 影响：计分板显示
  * 变更时机：每次正确点击

- 正计时计数
  * 用途：明确游戏已开始时间
  * 影响：时钟显示
  * 变更时机：每秒更新一次

- 步数计数
  * 用途：明确正确点击的次数
  * 影响：步数显示
  * 变更时机：每次正确移动卡牌

- 引导计时器
  * 用途：控制引导手指的显示时机
  * 影响：引导手指的显示和消失
  * 变更时机：玩家操作后重置，每秒递减

- 跳转计时器
  * 用途：控制自动跳转的时机
  * 影响：自动跳转
  * 变更时机：玩家操作后重置，每秒递减

2. 状态转换流程：
- 游戏开始流程
  1. 显示初始引导手指在第一步引导
  2. 等待玩家点击按照引导操作
  3. 点击后移除引导手指
  4. 启动游戏计时器
  5. 开始监听玩家操作

- 游戏进行流程
  1. 玩家点击卡牌
  2. 更新得分和显示
  3. 更新步数和显示
  3. 重置引导计时器
  4. 检查胜利/结束条件
  5. 继续游戏或触发结算画面

- 计时流程
  1. 每秒更新计时显示
  2. 更新相应的视觉效果

# Board组件实现

## 1. 属性
```typescript
image: Phaser.GameObjects.Image;        // 游戏背景
points: Phaser.GameObjects.Image[] = []; // 翻卡区域位置列表
isRightSide: boolean;                   // 判断是否为牌堆区域
```

## 2. 游戏区域处理
- 坐标计算：
  * 游戏区域部分：直接使用配置坐标
- 点击判定：
  * 牌堆区域使用矩形判定区域（Phaser.Geom.Rectangle）
  * 翻卡区域使用矩形判定区域（（Phaser.Geom.Rectangle）
  * 设置depth=100确保在最上层
  * 点击时发送side信息（'Calculate'或'Ready'）到事件系统

## 3. 点击成功判断
- 检查点击卡牌是否可移动：
  * 获取卡牌数值与花色：getCardValue(card)； getCardSuit(card)
  * 判断是否可以移动：isConsecutiveDescending(card1, card2)（数值）；isSameSuit(card1, card2)（花色）
  * 是否可以放置：isMovable(card, destinationPile)

## 4. 自适应处理
- 监听resize事件
- 重新计算裁剪区域
- 更新差异点位置和判定区域
- 保持图片比例不变
- 保持10px透明区域
