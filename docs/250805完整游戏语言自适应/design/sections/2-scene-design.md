# 3. 场景设计

## 3.1 游戏场景尺寸
- 竖屏模式：1080 x 2160 像素
- 横屏模式：2160 x 1080 像素
- 缩放策略：保持宽高比，自适应屏幕

## 3.2 UI组件布局与尺寸

### 注意：元素（包括a.数字;b.四种花色;c.JQK三种图标;d.卡槽）均需设定为可更换或改变尺寸

### 竖屏布局-游戏界面 (1080 x 2160)
1. 计分板区域（计分板、计时器、计步板）
   - 计分板图片：
     * 位置：x = (1080 - 计分板区域宽度) / 2，y = 50
     * h = 40 ，w自适应，比例不变

2. 游戏区域
   - 整体高度：1745px
   - 整体宽度：左右边距：20px
   - 位置：
     * x = (1080 - 总宽度) / 2
     * y = 计分板区域底部 + 65px

3. 卡槽及牌堆区域
   - 卡槽数：4
   - 卡槽区域与卡牌列区域前四列y对齐
   - 牌堆区域与卡牌列区域第七列y对齐


4. 卡牌列区域
   - 卡牌列数：7
   - 水平间距：5px
   - 垂直间距：30px
   - 起始位置：y = 计分板区域y + 计分板区域 + 卡槽区域 + 65px
   - 水平居中平均分布
   - 单张卡牌：150px * 210px

5. 底部ui区域
   - 大小：
     * 产品字体：w = 655 ，h = 90
     * 交互按钮：w = 627 ，h = 150
     * 退回按钮：w = h = 150
   - 位置：
     * 产品字体：x = (1080 - 总宽度) / 2 ，y = 1630
     * 交互按钮：x = 121 ，y = 产品字体y + 产品字体h + 80
     * 退回按钮：x = 交互按钮x + 交互按钮w + 45 ，y = 产品字体y + 产品字体h + 80
