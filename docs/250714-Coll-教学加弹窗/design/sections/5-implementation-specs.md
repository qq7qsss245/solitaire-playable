# 7. 详细实现规范

## 7.1 动画系统参数

1. 入场动画
- 透明度：从完全透明渐变到完全不透明
- 持续时间：0.7秒
- 缓动效果：带有弹性的缓出效果
- 牌堆与卡槽：入场即显示
- 卡牌入场：翻牌区域共七列牌，从左到右依次为第一列至第七列，入场后卡牌从牌堆区域依次飞入翻牌区，首列摆放一张卡牌...第七列摆放七张卡牌，每列最上方的牌明牌显示，其余牌均为背面
- 序列延迟：
  * 计分板区域：立即显示
  * 下载按钮：立即显示，显示后呈缩放效果

2. 正确点击或拖动特效
- 翻卡区卡牌正确点击：
  * 卡牌平移至其可摆放的位置
  * 卡牌原所处列的下一张卡牌翻开
  * 卡牌平移动画持续100毫秒
  * 翻卡动画持续100毫秒

- 牌堆区卡牌正确点击：
  * 若正确点击待翻开的牌堆，则翻开一张卡牌至牌堆左侧
  * 若正确点击牌堆区已翻开的卡牌，则卡牌平移至其可摆放的位置
  * 动画持续100毫秒

- 计分板更新：
  * 计分板中数字从原始大小放大至1.2倍后缩小为原始大小
  * 翻开卡牌不加分，卡牌正确摆放+10分
  * 动画持续400毫秒
  * 使用带有弹性的缓出效果

3. 错误点击动画
- 卡牌左右平移：
  * 平移范围：-15px到15px（相对于原始位置）
  * 单次平移用时100毫秒
  * 连续移动2次
  * 动画结束后回到原始位置

4. 引导手指动画
- 手指图标移动：
  * 水平和垂直方向同时移动20像素
  * 单次移动用时750毫秒
  * 使用正弦曲线实现平滑的来回移动
  * 无限循环播放
- 显示和消失：
  * 渐变显示
  * 任意点点击后即刻消失

## 7.2 事件系统

游戏中的核心事件包括：

1. 卡牌点击事件
- 触发条件：玩家点击到可移动或可翻开的卡牌
- 传递信息：
  * 卡牌原始位置信息
  * 卡牌移动后的位置信息
- 处理流程：
  * 更新游戏分数
  * 播放正确点击动画
  * 播放卡牌翻动音效
  * 更新计步板显示
  * 检查是否达到结束条件

2. 点击失误事件
- 触发条件：玩家点击到不可移动的卡牌 或 其他非游戏区域
- 点击到不可移动的卡牌处理流程：
  * 播放错误点击动画
  * 播放错误音效
- 点击到非游戏区域处理流程：
  * 不做任何反馈


3. 游戏结束事件
- 触发条件：50clicks
- 处理流程：
  * 停止所有游戏操作
  * 显示结算画面
  * 播放成功音效


4. 游戏胜利事件
- 触发条件：完成所有卡牌在卡槽中由小到大排序
- 处理流程：
  * 停止计时
  * 显示结算画面
  * 播放成功音效

## 7.3 状态管理

1. 游戏状态说明：

- 游戏开始标志
  * 用途：控制游戏是否已经开始
  * 影响：引导显示和计时启动
  * 变更时机：游戏开始4步引导完成后（5.2中内容），玩家首次点击点击时

- 当前得分
  * 用途：显示已正确点击的分数
  * 影响：计分板显示
  * 变更时机：每次正确点击

- 正计时计数
  * 用途：明确游戏已开始时间
  * 影响：时钟显示
  * 变更时机：每秒更新一次

- 步数计数
  * 用途：明确正确点击的次数
  * 影响：步数显示
  * 变更时机：每次正确移动卡牌

- 引导计时器
  * 用途：控制引导手指的显示时机
  * 影响：引导手指的显示和消失
  * 变更时机：玩家操作后重置，每秒递减

2. 状态转换流程：
- 游戏开始流程
  1. 显示初始引导手指在第一步引导
  2. 等待玩家点击按照引导操作
  3. 点击后移除引导手指
  4. 第2-4步引导按照该流程进行（5.2中内容）
  4. 启动游戏计时器
  5. 开始监听玩家操作

- 游戏进行流程
  1. 玩家点击卡牌
  2. 更新得分和显示
  3. 更新步数和显示
  3. 重置引导计时器
  4. 检查胜利/结束条件
  5. 继续游戏或触发结算画面

- 计时流程
  1. 每秒更新计时显示
  2. 更新相应的视觉效果

## 7.4 资源规格

1. 图片资源规范：

- 主要游戏图片
  * 尺寸：1083 x 912像素
  * 格式：JPG
  * 用途：包含左右两边的对比区域

- 界面元素
  * 标题：380 x 100像素，PNG格式
  * 时钟：80 x 80像素，PNG格式
  * 计分圆圈：40 x 40像素，PNG格式
  * 下载按钮：200 x 80像素，PNG格式
  * 游戏图标：303 x 303像素，PNG格式

- 特效图片
  * 星星：32 x 32像素，PNG格式
  * 手指：60 x 80像素，PNG格式
  * 错误标记：40 x 40像素，PNG格式

2. 字体设置：
- 字体大小：42像素
- 字体名称：自定义字体"font"
- 字体样式：粗体
- 文字颜色：可配置（当前为黑色）

## 7.5 性能优化规范

1. 图片资源优化：

- 格式选择
  * UI元素使用PNG格式，支持透明度
  * 背景和主图使用JPG格式，压缩率85%
  * PNG图片使用8位色深减小体积

- 加载策略
  * 游戏开始前预加载必要资源
  * 场景切换时加载对应资源
  * 使用加载进度条提示

2. 内存管理：

- 对象池管理
  * 适用对象：星星特效、错误标记、引导手指
  * 预创建数量：根据最大同时显示数量
  * 复用策略：使用完立即回收

- 资源释放
  * 及时销毁临时动画对象
  * 场景切换时清理旧场景
  * 定期检查未使用的资源

3. 事件管理：
- 及时解绑事件监听器
- 清理定时器和计时器
- 避免事件监听器累积

## 7.6 错误处理机制

1. 资源加载错误：
- 监测加载失败的资源
- 记录详细的错误信息
- 尝试使用备用资源
- 显示友好的错误提示

2. 游戏逻辑错误：
- 捕获并记录异常
- 保持游戏状态稳定
- 提供恢复机制
- 避免游戏卡死

## 7.7 调试功能

开发模式特性：
- 实时显示帧率
- 显示点击判定区域
- 输出详细日志
- 支持手动触发事件

## 7.8 点击判定机制

判定原理：
- 使用圆形判定区域
- 计算点击位置到中心点距离
- 考虑图片缩放比例
- 设置合理的判定范围

## 7.9 动画计算方法

动画实现原理：
- 使用线性插值计算过渡
- 应用不同的缓动函数
- 支持循环和往复动画
- 保证动画流畅性
