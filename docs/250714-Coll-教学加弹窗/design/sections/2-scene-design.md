# 3. 场景设计

## 3.1 游戏场景尺寸
- 竖屏模式：1080 x 2160 像素
- 横屏模式：2160 x 1080 像素
- 缩放策略：保持宽高比，自适应屏幕

## 3.2 UI组件布局与尺寸

### 竖屏布局 (1080 x 2160)
1. 计分板区域（计分板、计时器、计步板）
   - 计分板图片：
     * 位置：x = (1080 - 计分板区域宽度) / 2，y = 30
     * 使用原始尺寸

2. 游戏区域
   - 整体高度：1760px
   - 整体宽度：左右边距：15px
   - 位置：
     * x = (1080 - 总宽度) / 2
     * y = 计分板区域底部 + 50px

3. 卡槽及牌堆区域
   - 卡槽数：4
   - 卡槽区域与卡牌列区域前四列y对齐
   - 牌堆区域与卡牌列区域第七列y对齐


4. 卡牌列区域
   - 卡牌列数：7
   - 水平间距：5px
   - 垂直间距：35px
   - 起始位置：y = 计分板区域y + 计分板区域 + 卡槽区域 + 30px
   - 水平居中平均分布
   - 单张卡牌：147px * 230px

5. 引导文字区
   - 位置：
     * x = 540px（水平居中）
     * y = 990px
     整体高度：400px

5. 下载按钮
   - 位置：
     * x = 540px（水平居中）
     * y = 游戏区域底部 + 30px

6. 游戏图标
   - 尺寸：200 x 200像素
   - 位置：右下角，距离边缘10px

### 横屏布局 (2160 x 1080)
1. 计分板区域（计分板、计时器、计步板）
   - 计分板图片：
     * 位置：x =1810，y = 70
     * 使用原始尺寸

2. 游戏区域
   - 整体高度：900px
   - 整体宽度：左右边距580px
   - 位置：
     * x = (2160 - 总宽度) / 2
     * y = 10px

3. 卡槽及牌堆区域
   - 卡槽数：4
   - 卡槽区域与卡牌列区域前四列y对齐
   - 牌堆区域与卡牌列区域第七列y对齐


4. 卡牌列区域
   - 卡牌列数：7
   - 水平间距：5px
   - 垂直间距：35px
   - 起始位置：y = 卡槽区域y + 卡槽区域 + 15px
   - 水平居中平均分布
   - 单张卡牌：147px * 230px

5. 引导文字区
   - 位置：
     * x = 1080px（水平居中）
     * y = 580px
     整体宽度：830px
     整体高度：320px

5. 下载按钮
   - 位置：
     * x = 1080px（水平居中）
     * y = 游戏区域底部 + 30px

6. 游戏图标
   - 尺寸：200 x 200像素
   - 位置：右下角，距离边缘10px

## 3.3 卡牌位置信息
- 竖版：
   * 第一列第一排卡牌可点击范围：x：18-147px  y：500-750px
   * 每增加一列：x + 150px
   * 每增加一行：y + 35px
- 横版：
   * 第一列第一排卡牌可点击范围：x：585-725px  y：210-400px
   * 每增加一列：x + 145px
   * 每增加一行：y + 30px
