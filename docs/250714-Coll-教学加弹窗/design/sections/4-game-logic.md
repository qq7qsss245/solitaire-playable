# 5. 游戏逻辑

## 5.1 核心玩法
- 当前配置：
  * 卡牌总数：52
  * 卡牌花色：4
  * 倒计时时间：采用正计时
  * 结束条件：成功将所有卡牌按花色从小到大顺序排列至卡槽  或  50clicks
  * 叠放逻辑：在卡牌卡槽区域，卡牌按照由小到大顺序摆放，且卡槽只能摆放其对应花色的卡牌
            在卡牌翻牌区域，卡牌按照又大到小方式排列，且只能异色相叠，当翻牌区域有空位时，只能放置K

- 交互反馈：
  * 正确点击：当点击为明牌时，卡牌自动移动至对应位置
            当点击为牌堆时，翻开第一张卡牌
  * 错误点击：不做任何反馈

## 5.2 引导系统
- 初始引导1：（卡牌A移入对应的卡槽中）
  * 显示位置：任意卡牌A
  * 动画：手指图标循环移动（在卡牌A位置与对应花色卡槽间平移）
  * 触发条件：游戏开始时

- 初始引导2：（翻牌引导）
  * 显示位置：未翻开的牌堆
  * 动画：手指图标循环移动（上下平移20px）
  * 触发条件：完成第一步引导后

- 初始引导3：（翻开卡移动引导）
  * 显示位置：第二步引导翻开的卡牌
  * 动画：手指图标循环移动（在该卡牌位置与其能摆放的翻卡区域卡牌间平移）
  * 触发条件：完成第二步引导后

- 初始引导4：（翻卡区移动引导）
  * 显示位置：翻卡区任意可移动的卡牌
  * 动画：手指图标循环移动（在该卡牌位置与其能摆放的翻卡区域卡牌间平移）
  * 触发条件：完成第三步引导后

- 游戏中引导：
  * 显示位置：1.任意可移动的卡牌  2.当无卡牌可移动时，则显示于牌堆区域
  * 动画：1.在该卡牌位置与其能摆放的区域间平移  2.手指于牌堆区域进行缩放范围为80-120%
  * 触发条件：5秒无操作
  * 消失条件：任意点击

## 5.3 计分系统
- 显示方式：计分板
- 更新逻辑：
  1. 正确点击卡牌
  2. 卡牌移动至对应区域
  3. 若正确点击的卡牌下仍有余牌则自动翻开此牌
  4. 指示器更新为正确状态

## 5.4 计步系统
- 显示方式：计分板
- 更新逻辑：
  1. 正确点击卡牌 或 点击牌堆区域进行翻牌
  2. 指示器更新为正确状态

## 5.5 自适应布局系统
- 监听事件：window.resize
- 处理逻辑：
  1. 检测屏幕方向
  2. 更新游戏场景尺寸
  3. 重新计算所有UI元素位置
  4. 重新计算差异点位置和大小

## 5.6 性能考虑
- 当前资源尺寸：未优化
- 动画实现：使用Phaser.Tweens
- 事件系统：使用自定义EventBus
- 内存管理：
  * 正确销毁临时对象（如动画特效）
  * 适当缓存频繁使用的对象
