# AutoComplete按钮深度层级修复说明

## 问题描述

用户反馈AutoComplete按钮的渲染优先级要比deck里的卡牌高，这是一个深度层级（z-index/depth）问题。AutoComplete按钮被deck卡牌遮挡，说明其深度层级设置不正确。

## 问题分析

### 修复前的深度层级设置：
- **AutoComplete按钮**: 深度为 100
- **下载按钮（PlayNow按钮）**: 深度为 20
- **卡牌**: 深度基于其Y坐标位置（通常在几百到一千多）
- **Foundation卡牌**: 深度为 10 + 卡牌在堆中的位置
- **暗色蒙版**: 深度为 10

### 问题根源：
卡牌的深度是基于Y坐标设置的（`card.setDepth(y)`），这意味着tableau区域的卡牌深度可能会达到几百甚至上千，这比AutoComplete按钮的深度100要高，所以会遮挡按钮。

## 修复方案

### 新的深度层级体系：
- **卡牌**: 深度基于Y坐标（0-1500范围）
- **Foundation卡牌**: 深度为 10 + 卡牌在堆中的位置（10-25范围）
- **暗色蒙版**: 深度为 10
- **下载按钮（PlayNow按钮）**: 深度为 20
- **AutoComplete按钮**: 深度为 2000（修复后）

### 修复内容：

1. **创建AutoComplete按钮时设置深度**：
   ```typescript
   // src/game/scenes/Game.ts:758
   this.autoCompleteButton.setDepth(2000); // 确保在所有游戏元素之上，包括卡牌
   ```

2. **位置更新时保持深度**：
   ```typescript
   // src/game/scenes/Game.ts:1099
   this.autoCompleteButton.setPosition(buttonConfig.x, buttonConfig.y);
   // 确保深度层级始终正确，高于所有游戏元素
   this.autoCompleteButton.setDepth(2000);
   ```

3. **显示按钮时确保深度**：
   ```typescript
   // src/game/scenes/Game.ts:1198
   if (shouldShow && !isCurrentlyVisible) {
       console.log('🔘 显示AutoComplete按钮');
       this.autoCompleteButton.setVisible(true);
       // 确保深度层级正确，高于所有游戏元素
       this.autoCompleteButton.setDepth(2000);
   }
   ```

4. **测试模式强制显示时确保深度**：
   ```typescript
   // src/game/scenes/Game.ts:2062
   if (this.autoCompleteButton) {
       this.autoCompleteButton.setVisible(true);
       // 确保深度层级正确，高于所有游戏元素
       this.autoCompleteButton.setDepth(2000);
   }
   ```

## 修复后的深度层级体系

```
深度层级（从低到高）：
├── Foundation卡牌: 10-25
├── 暗色蒙版: 10
├── 下载按钮: 20
├── 卡牌: 0-1500（基于Y坐标）
└── AutoComplete按钮: 2000 ✅
```

## 技术细节

- 使用深度值2000确保AutoComplete按钮始终在最前面
- 在所有可能影响按钮显示的地方都设置了深度
- 保持与现有UI层级体系的兼容性
- 不影响其他重要UI元素的显示
