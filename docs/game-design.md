# 纸牌接龙游戏设计文档

## 游戏概述
这是一个基于经典纸牌接龙的可玩广告游戏,玩家需要通过合理的策略移动和组织卡牌,最终将所有卡牌按花色和顺序收集完成。

## 界面布局

### 1. 信息显示区域
- 位于屏幕顶部
- 左侧显示移动次数(Moves: X)
- 右侧显示当前得分(Score: X)

### 2. 游戏主区域布局
#### 2.1 顶部收牌区(Foundation)
- 位于游戏区域顶部
- 包含4个卡牌位置,对应四种花色(红桃♥、黑桃♠、梅花♣、方块♦)
- 每个位置从A开始,按升序排列到K(A->2->3...->K)
- 初始状态为空

#### 2.2 中间操作区(Tableau)
- 7列纸牌阵列
- 每列从左到右依次放置1-7张牌
- 每列最底部的牌正面朝上,其他牌背面朝上
- 卡牌按红黑交替、数字递减排列

#### 2.3 右上角发牌区(Stock & Waste)
- Stock区:未使用的卡牌背面朝上堆叠
- Waste区:从Stock区翻出的卡牌正面朝上显示

### 3. 右侧十字牌局初始布局
#### 3.1 十字布局结构
- 由7个位置组成的十字形布局
- 中心位置为3列纵向牌堆
- 左右两侧各有2个卡牌位置

#### 3.2 具体牌面分布
左侧(从上到下):
- 第一组:
  * 3张背面朝上的牌
  * 底部为5♥(红心5)
- 第二组:
  * 4张背面朝上的牌
  * 底部为10♣(梅花10)

中间三列(从左到右):
- 左列: 共16张牌
  * 15张背面朝上的牌
  * 底部为4♠(黑桃4)正面朝上
- 中列: 共16张牌
  * 15张背面朝上的牌
  * 底部为8♠(黑桃8)正面朝上
- 右列: 共16张牌
  * 15张背面朝上的牌
  * 底部为7♥(红心7)正面朝上

右侧(从上到下):
- 第一组:
  * 4张背面朝上的牌
  * 底部为A♥(红心A)
- 第二组:
  * 4张背面朝上的牌
  * 底部为J♣(梅花J)

#### 3.3 牌堆特点
- 中间三列每列均为16张牌
  * 每列有15张背面朝上的未知牌
  * 每列底部有1张正面朝上的已知牌
- 左侧两组分别为:
  * 第一组:4张牌(3张背面朝上+1张正面朝上)
  * 第二组:5张牌(4张背面朝上+1张正面朝上)
- 右侧两组各为5张牌
  * 每组有4张背面朝上的未知牌
  * 每组底部有1张正面朝上的已知牌
- 所有背面朝上的牌需要通过游戏过程逐步翻开
- 初始可见的牌面为关键的游戏开局提示

## 游戏规则

### 1. 基本移动规则
- 卡牌移动必须遵循红黑交替规则
- 数字必须按降序排列(K->Q->J->10...->2->A)
- 空列只能放置K作为开始
- 可以移动单张卡牌或符合规则的连续多张卡牌

### 2. 收牌规则
- 收牌区按花色独立收集
- 必须从A开始,按升序依次收集(A->2->3...->K)
- 每个花色需要收集完整的13张牌

### 3. 发牌操作
- 点击Stock区可以翻开新卡牌到Waste区
- Waste区的卡牌可以按规则移动到任意合法位置
- Stock区卡牌用完后可以重新收集Waste区卡牌重新发牌

### 4. 计分系统
- 移动卡牌到收牌区:+10分
- 翻开新卡牌:+5分
- 移动次数记录每次有效的卡牌移动

## 游戏目标
1. 主要目标:将52张卡牌按花色顺序收集到顶部收牌区
2. 挑战目标:
   - 尽可能减少移动次数
   - 获得更高的分数

## 操作提示
1. 优先翻开未知卡牌,增加可见信息
2. 合理利用空列进行卡牌临时存放
3. 注意规划长序列的移动路径
4. 优先处理阻碍大量卡牌的堆叠

## 关键特性
1. 自动判定移动合法性
2. 连续卡牌序列的一键移动
3. 实时分数和移动次数统计
4. 操作音效反馈
5. 胜利条件自动判定
