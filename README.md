# 纸牌接龙游戏说明文档

## 游戏界面布局

### 主要区域
1. 顶部信息区
   - 左侧显示移动次数 (Moves)
   - 右侧显示得分 (Score)

2. 游戏区域布局
   - 顶部区域:4个空位(Foundation Piles),用于最终收集整理好的卡牌
   - 中间区域:7列纸牌(Tableau Piles),用于主要的游戏操作
   - 右上角:发牌区(Stock Pile)和翻开区(Waste Pile)

### 卡牌布局细节
1. 发牌区(右上)
   - 未使用的卡牌背面朝上堆叠
   - 可以点击发牌区抽取新卡牌

2. 中间七列(从左到右)
   - 每列卡牌数量依次递增(1-7张)
   - 每列最底部的卡牌正面朝上
   - 其余卡牌背面朝上
   - 展示的卡牌按照花色和数字交替排列

3. 顶部收牌区
   - 四个空位分别对应四种花色
   - 从A开始按顺序往上收集(A->2->3...->K)

## 游戏规则

### 基本规则
1. 卡牌移动规则
   - 红黑花色交替排列
   - 数字需要按降序排列(K->Q->J->10...->2->A)
   - 空列只能放置K

2. 收牌区规则
   - 必须按照同一花色
   - 必须按照升序(A->2->3...->K)
   - 每个花色独立收集

### 操作方式
1. 发牌操作
   - 点击发牌区抽取新卡牌
   - 抽取的卡牌会显示在发牌区旁边

2. 移动操作
   - 点击并拖动卡牌到目标位置
   - 可以移动单张或多张连续排列正确的卡牌

### 计分规则
1. 基础得分
   - 每移动一张卡牌到收牌区:+10分
   - 每翻开一张新卡牌:+5分

2. 移动次数计算
   - 每次有效的卡牌移动都会增加移动次数

## 游戏目标
1. 主要目标
   - 将所有52张卡牌按照花色和顺序收集到顶部四个收牌区

2. 次要目标
   - 尽可能减少移动次数
   - 获取更高的分数

## 游戏策略建议
1. 优先翻开未知卡牌
2. 注意保持空列的战略价值
3. 合理规划卡牌移动顺序
4. 优先处理阻碍较大的卡牌堆
